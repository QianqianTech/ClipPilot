# 海外平台增量接入任务清单

适用工程：`VideoBrowseAssistant`  
目标版本：`0.7.x`（规划）  
状态：`DONE` 已有基础，`TODO` 待开发，`VERIFY` 待真机或人工验收，`HOLD` 依赖平台规则、设备、地区或发布条件。

## 0. 本次变更边界

本次只是在现有视频浏览助手上增加六个平台选项：TikTok、YouTube Shorts、Instagram Reels、Kwai、X、REDnote。

现有的软件能力直接复用：

- 现有多平台勾选和平台顺序；
- 现有 `SessionTaskQueue` 队列、每个平台视频配额和会话快照；
- 现有 `AutoSwipeAccessibilityService` 前台包名判断和上滑手势；
- 现有自动切换、15 秒前台确认、30 分钟上限、通知栏停止、屏幕常亮和运行诊断；
- 现有内容定向、评论辅助和模型网关保持原状，不因增加平台重新设计。

本次不新增注册、登录、账号状态、账号资料、账号切换、密码/验证码处理或任何自动互动功能。平台 App 是否能显示视频由官方 App 自身决定；助手只负责启动已安装 App、执行现有浏览逻辑、统计和停止。

推荐顺序：

1. 在现有 `TargetApp` 列表和 Manifest 查询中加入六个平台。
2. 用现有队列和服务完成本地单测、构建和静态检查。
3. 逐个平台确认启动、视频入口、上滑、计数、停止和自动切换。
4. 完成两台真机矩阵、规则审核、文档更新和发布门禁。

完成定义：代码只增加平台配置和必要的平台兼容处理；现有队列、手势、停止和通知回归通过；六个平台分别完成真实设备验证；任何未通过平台保持关闭或 `VERIFY/HOLD`，不影响原有软件使用。

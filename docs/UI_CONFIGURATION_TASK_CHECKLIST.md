# 视频浏览助手：首页配置分组与任务统计改造清单

状态：`DONE` 已完成本轮分析或文档；`TODO` 待开发；`VERIFY` 待真机、人工或视觉验收；`HOLD` 依赖外部条件、政策或发布审批。

## 1. 本轮分析结论

当前首页由一个 `ScrollView` 承载所有功能。`MainActivity.buildContent()` 依次放入使用边界、无障碍服务、11 个平台复选框、平台配额、上滑说明、自动执行、屏幕常亮、内容定向、智能评论、模型网关、会话状态和运行诊断。平台选择从 `MainActivity.java:264` 开始，内容定向从 `:436` 开始，评论从 `:533` 开始，模型网关从 `:734` 开始；这些内容必须连续向下滚动才能操作。

当前已有两个真正的下拉控件：评论“内容方向”和模型网关“后台模型档位”。它们不是主要长度来源，但应在分组后继续保留为配置项，不应在首页同时展开。

改造前会话只有 `completed_task_count`、`skipped_task_count`、`active_task_index` 和 `active_task_video_count`。本轮已增加 `TaskStatsStore`，把视频、平台、批次和跳过数保存为本机累计数据，并保留最近 20 条批次摘要；旧会话键仍保持单次会话语义。

## 2. 目标信息架构

首页只保留状态、统计和一个主操作；详细设置进入四个配置/管理项。普通用户默认看到摘要，点卡片后才进入详情，避免把 11 个平台和高级字段一次性铺开。

| 入口 | 默认显示 | 详情内容 | 原页面内容 |
| --- | --- | --- | --- |
| **首页 / 任务概览** | 无障碍状态、当前会话、最近一次结果、累计完成数、`启动任务` | 当前批次进度、停止会话、最近一次摘要 | 会话状态、主按钮、任务摘要 |
| **任务配置** | 已选平台数量、每个平台数量、预计任务量 | 平台选择、国内/国际分组、配额、上滑节奏、内容定向 | 执行任务、内容定向 |
| **互动配置** | 评论辅助和模型网关是否开启 | 评论关键词/方向、暂停读取、候选生成、网关地址/档位/令牌 | 智能评论、模型网关 |
| **运行管理** | 服务是否开启、自动执行/常亮开关 | 无障碍引导、自动执行、屏幕常亮、运行诊断、清理诊断 | 无障碍服务、运行诊断、部分会话操作 |
| **统计与记录** | 完成平台任务、完成视频任务、完成批次、跳过数、完成率 | 按日期/平台查看最近记录，清除统计（与清除诊断分开） | 新增页面 |

“平台任务”指一个平台完成其配额；“视频任务”指成功完成并上滑的视频数量；“批次”指一次点击启动后结束的整组队列。三者必须使用不同文案，避免把当前的 `completed_task_count` 误读成视频总数。

## 11. 完成定义

- 首页首屏能看到服务状态、当前任务/最近结果、累计完成数和唯一主操作；无需连续滚动才能开始任务。
- 平台、配额、内容定向、评论、模型网关、无障碍、自动执行、常亮和诊断均能从对应配置/管理项进入；高级内容默认收起。
- 现有 `SharedPreferences` 配置键、会话队列冻结、通知栏停止、前台限制、30 分钟上限和“不会自动点赞/收藏/发送”边界保持不变。
- 统计明确区分批次、平台任务和视频任务；正常完成、部分跳过、停止、异常和清除统计均有可解释结果。
- 本地构建通过后，真机证据单独记录；不能用静态页面、单元测试或 APK 打包结果替代真机 UI 和无障碍验收。

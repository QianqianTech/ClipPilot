# 视频浏览助手 APK 任务方案

## 1. 目标和交付物

交付一个可安装的 Android 调试 APK，用于个人无障碍辅助和自有应用交互测试：用户明确开启无障碍服务后，可勾选多个已安装平台并生成任务队列；每个平台按 2–100 个视频配额执行前台上滑，每条视频在 10–30 秒内随机等待后上滑，完成后自动切换到下一平台，整批最长 30 分钟。0.5.0-dev 提供本地内容定向，0.4.0-dev 提供本地评论辅助；0.6.2 统一内置模型网关配置与服务端 `CommentModelGateway` 档位管理，不再拆分 offline/ai APK。只有用户在暂停视频后手动点击生成、确认披露并获得后台设备令牌时才调用 HTTPS 网关；最终发送仍由用户完成。交付物包括 Android 源码、服务端网关、构建说明、单一 APK、验证记录和待发布清单。

## 2. 范围边界

- 允许：多选用户明确选择的已安装应用、按用户勾选先后顺序分配视频任务、判断当前任务包名是否在前台、执行固定轨迹上滑、完成后自动拉起下一应用、显示进度和停止入口；用户明确开启内容定向并填写方向后，在当前目标视频页读取最少可访问文字，在本机决定命中停留或无关跳过；用户从通知栏明确触发后，在暂停状态读取当前页面可访问文字，生成本地候选并填入用户已聚焦的评论输入框；在统一版本中，用户二次确认后可把最多 360 个字符的页面文字、关键词和方向发往服务端 HTTPS 模型网关。
- 禁止：自动登录或保存账号密码，自动点赞、自动收藏、自动发送评论、关注、分享、私信、购买，自动处理验证码，读取账号或消息，绕过风控，隐藏运行，利用随机等待模拟真人或规避平台检测，批量账号或批量设备操作。10–30 秒随机等待只作为用户可见的浏览节奏，不改变上述边界。
- 运行条件：用户主动开启系统无障碍服务；只在当前任务应用位于前台时运行；单次 30 分钟硬上限；通知和应用内状态可见。统一版本只接受 HTTPS 网关地址，并要求用户手动启用网关与粘贴不落盘的设备令牌；模型请求默认关闭。评论文字只在用户明确点击“暂停并读取”时短时保留，恢复、停止、超时或服务断开后清除；同样路径会取消在途网关请求。Android 单前台约束下按队列顺序执行，不承诺真正并行。
- 发布边界：当前仅 debug 构建。未完成正式签名、商店审核、隐私政策、无障碍用途声明和不同厂商真机兼容性前，不作为生产发布包。

## 3. 阶段计划

### 阶段 A：需求和合规确认

明确目标用户、允许的目标应用、设备版本、是否只服务自有应用；确认目标平台规则、无障碍服务披露和隐私政策要求。输出范围确认记录和风险清单。

### 阶段 B：MVP 工程

完成启动页、无障碍设置引导、多平台勾选、每平台 2–100 个视频配额、10–30 秒随机上滑节奏、队列快照、平台内/整批进度、自动切换、启动/停止、前台包名判断、从会话开始计时的 30 分钟上限、可见通知和本地状态存储。切换失败或 15 秒内未进入前台时跳过该平台并继续后续任务。增加用户主动开启的“下次启动助手时自动执行”模式、通知栏停止入口和会话期间屏幕常亮选项。0.5.0-dev 增加独立的内容定向披露、想看/不想看词项、会话快照、本地规则匹配、命中/扫描双配额、扫描/连续未命中保护、可解释状态和短时会话清理；0.4.0-dev 增加“暂停并读取 / 填入草稿 / 恢复浏览”、关键词/方向、本地候选与短时清理。屏幕常亮使用带 30 分钟超时的唤醒锁，并在所有停止路径释放。统一版本默认不发起网络请求，只有用户显式启用模型网关后走 HTTPS；无账号、不做开机后台拉起。

海外平台扩展按[专项任务清单](OVERSEAS_PLATFORM_TASK_CHECKLIST.md)单独推进：直接复用现有 `TargetApp`、`SessionTaskQueue`、无障碍上滑、自动切换、通知停止和进度逻辑，只增加六个平台配置、Manifest 查询、必要的平台兼容处理和真机验证。账号、登录、互动和原有队列重做不进入该阶段。

### 阶段 C：模型网关与后台配置

实现 `CommentModelGateway`：版本化请求协议、设备鉴权、档位路由、服务端环境变量密钥、超时、内存限流、短时幂等结果、候选安全/去重过滤和后台档位管理页。Android 只保存 HTTPS 网关根地址与档位；设备令牌只存内存。真实供应商、企业身份服务、数据保留、持久审计与成本计量必须单独配置和验收。

### 阶段 D：构建和自动化验证

使用 JDK 17、Gradle 8.11.1、Android SDK 36 构建 debug APK；运行队列单元测试、Lint、Manifest 权限检查、ZIP/对齐/签名静态检查和关键逻辑验证。记录 SHA-256、版本号和构建时间。

### 阶段 E：真机验收

至少用一台 Android 10+ 真机验证开启/关闭无障碍、抖音/快手/微信视频号/B站队列顺序、自动切换、页面恢复、切换失败跳过、停止、超时、重启和卸载。另验证内容定向的正向命中、强排除、文字不足、扫描上限、通知/主页同步、停止后不再读取，以及“暂停并读取”、短时文字清除、候选生成、聚焦输入框填入和用户手动发送的完整链路。统一版本还需在受控 HTTPS 网关验证披露、令牌失效、取消、超时、限流、网关故障与不自动发布。平台覆盖只作为兼容性观察，不承诺任何第三方平台内部页面都能被自动操作。

### 阶段 F：正式发布准备

补充正式签名、隐私政策、无障碍用途说明、崩溃和权限说明、兼容性矩阵、可撤销的会话记录、应用商店审核材料和回滚方案。只有在平台政策允许且完成书面审核后，才评估正式分发。

## 4. 验收标准

1. APK 可以安装并启动；首次启动不会自动打开第三方应用或自动运行会话。
2. 无障碍服务未开启时，点击开始会引导到系统设置，不会静默执行。
3. 未安装平台不可选；当前任务应用离开前台、服务关闭或用户点击停止时，不发送上滑手势。
4. 每个平台达到配额后切换到下一平台；切换失败可跳过并继续，主页和通知显示当前/总体进度。
5. 会话最多持续 30 分钟，停止后不保留运行状态；应用重启不会恢复旧会话。
6. 统一 APK 声明 `INTERNET` 仅用于可选 HTTPS 网关，默认关闭在线请求；不含账号、消息或验证码上传逻辑。
7. 在线生成由用户显式触发；模型/API Key 不在 APK、SharedPreferences、诊断或日志中。
8. 构建产物、版本、SHA-256 和验证命令都有记录；正式发布门禁未完成时明确标注为 debug 或 unsigned/HOLD。

## 5. 风险和处置

- 第三方应用页面经常变动：只做包名和前台状态判断，不依赖页面控件坐标之外的内容识别；出现不兼容时停止会话并记录设备信息。
- 微信和 B站入口不能仅靠包名定位：要求用户先进入一次对应视频页，后续拉起尽量恢复任务栈；无法恢复时暂停并等待用户处理。评论辅助只在用户明确触发时读取可访问文字，不依赖坐标识别或自动打开评论区。
- 内容定向依赖目标页面是否公开可访问文字：文字不足、页面节点变化或平台拒绝暴露内容时一律降级为“无法判断”，不使用 OCR、录屏、音频抓取或坐标猜测绕过。
- 模型供应商、企业身份、数据保留和费用由后台控制：默认关闭模型网关；没有 HTTPS、服务端密钥、设备令牌和留存批准时保持本地候选，不能把供应商密钥写入 APK。
- Android 后台 Activity 启动限制和厂商策略可能阻止自动切换：使用 15 秒可见超时、诊断和跳过机制，并以真机兼容性矩阵作为发布门禁。
- 厂商系统可能限制无障碍后台行为：以真机结果为准，不通过隐藏保活或绕过系统限制解决。
- 平台规则可能限制自动化浏览：正式分发前由产品和法务确认；无法确认时只保留本地演示和自有应用测试模式。
